Privacy notice

Trafirdis is an independent, unofficial interface for your personal Plex library. This notice describes the application, not Plex's own data practices.

Connections and data

The application reads movie metadata, artwork and watch status from the Plex Media Server configured by your deployment. Preview streams pass through the same fixed server proxy. There is no Trafirdis account service, database, analytics SDK or telemetry.

Sign in with Plex opens Plex's official website. Passwords and two-factor codes stay there. The browser contacts Plex's authentication and resource APIs to authorize access and identify the configured server. The account token is used transiently for this lookup; only the verified server token is saved for the browser session. Manual token entry avoids the hosted sign-in requests.

Local storage and diagnostics

The server access token and unfinished sign-in state use this tab's session storage. A public client identifier uses local storage, with session and memory fallbacks, to preserve this app instance's identity. Catalog and trailer caches stay in memory. The sample library uses local fictional content.

Disconnect clears local access and catalog caches. It does not revoke Plex's Authorized Devices entry; manage that through Plex's account settings. Browser extensions and scripts with access to this origin may read session tokens. Native artwork/video URLs contain authentication, so browser tools and an additional reverse proxy may see it. Built-in request logging is disabled or sanitized, and HTTP LAN traffic is not encrypted.

Optional diagnostics create reports locally when you choose Download report. Reports include numeric movie IDs and observations, excluding titles, credentials, addresses and stream URLs. They are not uploaded automatically; any sharing is your choice.

Your deployment

Your deployment operator controls the Plex address, network exposure and any additional proxy logs. Clearing browser data removes stored access and the public client identifier. Consult Plex's policies for Plex's processing and account controls.
